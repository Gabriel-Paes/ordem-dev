# Módulo 1 — Versionamento com Git

> A máquina do tempo do seu código.

## O que você vai aprender

- Git como sistema distribuído: o que muda em relação a ferramentas centralizadas
- Comandos essenciais: `init`, `clone`, `add`, `commit`, `push`, `pull`, `merge`, `rebase`
- Fluxo com GitHub: fork, branches, pull requests
- Code review: como dar e receber feedback técnico

## Pré-requisitos

Nenhum. Só uma conta no GitHub.
